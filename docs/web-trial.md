# 网页试用说明

这是面向用户的第一版选型交互原型。输入描述、核对明确参数、生成候选组件，再看检查和原文依据。
目前范围为 HA-010、10 个普通接点另加 PE、电缆端到面板端；线缆由用户提供。
支持螺钉、压接和普通弹簧，其他系列/接点数不会自动替换成 HA-010。

## Windows 上直接试用

1. 打开 GitHub 中的 [demo/index.html](../demo/index.html)，点击右上角 **Download raw file / 下载原始文件** 按钮。
2. 保存为 `index.html`，右键选择用 Edge 或 Chrome 打开。这个页面无需安装 Python、数据库或填写 API 密钥。
3. 点击“24V / 3A 基础方案”，核对左侧参数，点击“生成候选方案”。
4. 依次试下表中的例子。修改参数后，需要重新生成；旧结果不能继续导出。

GitHub 的代码浏览页只显示源码，不会运行网页。请下载 HTML，用浏览器打开；不要用 WPS 打开 HTML。
当前没有公开部署网址。仓库推送和公开网站部署是两件事。

| 例子 | 预期观察 |
| --- | --- |
| 24V / 3A 基础方案 | 5 类候选组件，状态仍为待确认，不是工程批准 |
| 两套压接方案 | 7 类组件，公、母普通压接端子各需要 20 个；PE 和工具另外核对 |
| 17A 超额定测试 | 不符合条件，清单仅用于排查原因 |
| 缺参数测试 | 缺少导线截面积、线缆外径及温度；相关组件保留待选定 |
| 手动改为 8 个普通接点 | 显示超出范围，不自动换成 10 接点 |

页面可以导出 UTF-8 CSV，包含输入、候选型号、数量、结果状态、检查及装配要求。
实际需要数量与包装取整建议分别显示；包装数据仍需审核。原文依据标签显示整本 PDF 文件页序。

## 两个版本的区别

| 项目 | 下载的单文件版本 | 连接数据库的版本 |
| --- | --- | --- |
| 入口 | `demo/index.html`；运行服务时也可访问 `/demo` | 服务根路径 `/` |
| 数据 | 构建时的 48 条样板产品投影及部分参数；不是全库 | 实时读取样板库，调用已有 `/selection/ha010` |
| 检查 | 基础标称值/范围/数量初筛，始终不能最终批准 | 服务端依赖、适配关系、工程审核及本次工况检查 |
| 原图 | 只有来源页码，不含 PDF 图片 | 可打开资料库原始页面 |
| 网络 | HTML 内含所有样式、脚本和数据；CSP 禁止网络连接 | 同源 API 请求，失败时明确提示，不暗中降级 |

两个版本均没有接入大模型。描述识别仅支持有限、明确的中英文数字和单位，参数必须人工核对。
冲突/范围值会留空；普通接点/PE 和每接点电流语义不明确时需要确认。
特殊要求或复杂否定语句可能不能完整理解；当前页面不能替代完整的自然语言 Agent。

实际库的 80 个产品仍待审核，没有真实工程批准的 BOM。所有例子都是软件试验。
下载版没有完整的依赖递归、真实配对关系和工程记录，因此不能用下载版代替服务端完整校验。
压接工具不计入成品 BOM，但需要按端子、线径及厂家工艺选定；PE、密封和附件完整性仍需工程依据。

## 开发与验证

按 README 启动数据库及 API。根路径是本试用页；原资料审核页已移动到 `/workbench`。
此服务目前只允许本机 Host，未作为公开网站部署；不要直接把含审核写入功能的本地服务暴露到公网。
公开部署属于后续运维工作，需要将用户查询与受保护的资料维护入口配置好。

```bash
.venv/bin/python -m scripts.build_trial
node tests/trial_core.test.cjs
.venv/bin/python -m pytest -q
WAIN_TEST_URL=http://127.0.0.1:8000 uv run --no-project --with playwright python -m scripts.check_trial_ui
WAIN_TEST_URL=http://127.0.0.1:8000 uv run --no-project --with playwright python -m scripts.check_ui
```

`build_trial` 只投影指定样板型号和允许的参数字段，不打包数据库文件、凭证、OCR 或原 PDF。
源数据更新后要重新构建下载版；不要把旧下载文件当成实时库。

本批 Chromium 已验证数据库版本，以及通过 HTTP 提供的原封不动单文件 HTML，后者没有发起任何后续网络请求。
云浏览器管理员策略禁止 `file://`，因此没有完成该环境中的双击打开验证，没有改动或绕过浏览器策略。
下载后用 Windows 浏览器打开仍需目标用户验收。

后续在这个页面上继续接入模型工具调用、多轮追问、更多系列、方案版本和公开访问。
