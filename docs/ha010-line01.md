## 1. 先固定范围

选 HA-010 普通螺钉款（不含 /B），10 个普通接点另加 PE，一套可分离连接器，侧进线，面板安装。暂按公芯体在电缆端、母芯体在面板端整理，实际供电侧和防触电要求确认后才能固定公母安装方向。

这一条“线”指一套连接链路，不是已经定义好长度、线色和两端设备端子的成品线束。线缆、面板内导线和设备侧端接也必须计入交付范围，但规格、长度和采购号目前NA。

```text
外部线缆（规格/长度待定，普通导体与 PE）
  → 电缆接头 WNA-M20(D6-12)〔仅在外径合适且螺纹/密封核实后〕
  → 电缆端外壳 H10A-SE-2B-M20
  → 公芯体 HA-010-M（暂定电缆端）
  ⇄ 母芯体 HA-010-F（暂定面板端）
  → 面板底座 H10A-BK-1L/SC
  → 面板内导线 / PE 接地路径 → 设备端子（待定义）
```

外壳、底座和接头是包覆、固定与密封部件；上图是装配路径，不表示电流经过电缆接头或外壳。PE 要单独核对，不能当第 11 个普通接点使用。

## 5. 可直接给技术人员的确认问题

请核对 HA-010-M（1210100110001）、HA-010-F（1210100210001）、H10A-SE-2B-M20（1100105101002）、H10A-BK-1L/SC（1100103211001）、WNA-M20(D6-12)（1021070151001）是否可组成一套侧进线到面板连接器：

1. 公母芯体、外壳、底座及 L/SC 锁扣是否确切适配？请提供配对和安装依据。
2. 外壳入口是否 M20×1.5？8 mm 螺纹长度是否适用？密封圈、螺母、面板垫片、安装螺钉是否随件？另购件请给订货号和数量。

5. 实际工况填齐后，请核对降额、针位、防触电和温度条件；未填齐前不要求批准。
