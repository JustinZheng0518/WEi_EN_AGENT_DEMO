# HA-010 完整选型闭环进度

## 第一步：审核工作台

已实现中文页面：左侧审核队列，中间 PDF 原图，右侧字段和审核记录；支持桌面与移动布局。
产品身份、参数、适配关系、原文证据和 OCR 候选分别审核，填写实际审核人标识和具体依据。

审核 API 支持字段更正、版本冲突检查、事务回滚和修改前后审计。
修改已确认来源或产品身份会撤回相关审核，避免旧的兼容结论继续生效。
局部确认不代表完整方案通过。候选文字确认不会自动变成产品。

验证：18 项数据库/API 集成测试通过；界面另用 Chromium 做功能检查。
目前是本地工具，没有外部发布或多用户认证。

已对照目录第 469、470、1401 页，导入两款 M20 外壳、一款面板底座和三款电缆接头；
夹紧范围分别为 4–8、6–12 和 8–14mm。为 HA-010 芯体补充有来源的接线截面积范围。
所有新增记录均待审核，不生成未经证实的配对关系。

验证：配套导入测试通过，重复执行不增加重复产品或覆盖审核状态。
