# HA-010 完整选型闭环进度

## 第一步：审核工作台

已实现中文页面：左侧审核队列，中间 PDF 原图，右侧字段和审核记录；支持桌面与移动布局。
产品身份、参数、适配关系、原文证据和 OCR 候选分别审核，填写实际审核人标识和具体依据。

审核 API 支持字段更正、版本冲突检查、事务回滚和修改前后审计。
修改已确认来源或产品身份会撤回相关审核，避免旧的兼容结论继续生效。
局部确认不代表完整方案通过。候选文字确认不会自动变成产品。

验证：18 项数据库/API 集成测试通过；界面另用 Chromium 做功能检查。
目前是本地工具，没有外部发布或多用户认证。

## 第二步：HA-010 配套数据

已对照目录第 469、470、1401 页，导入两款 M20 外壳、一款面板底座和三款电缆接头；
夹紧范围分别为 4–8、6–12 和 8–14mm。为 HA-010 芯体补充有来源的接线截面积范围。
所有新增记录均待审核，不生成未经证实的配对关系。

锁扣选择依据另追溯至第 445 页，组件角色依据第 57 页。
外壳只写 M20，而接头写 M20x1.5，因此螺距和有效啮合长度需要单独核对；
IP 等级也不能仅取某一个零件的标称等级。

验证：配套导入测试通过，重复执行不增加重复产品或覆盖审核状态。

## 第三步：候选 BOM 与完整性检查

已实现 `POST /selection/ha010` 及中文表单。范围是线缆由用户提供的电缆到面板连接器组件。
螺钉/弹簧方案包含五类组件；压接方案增加公、母端子，按普通接点数及套数计算数量。
包装取整与需要数量分开记录，未审核包装只作为核对建议。

检查包括：产品类别、普通接点和 PE、额定电压电流、导线截面、线缆外径、材料温度边界、
产品及参数审核、型号级适配关系，以及额外必需附件依赖。
降额、螺纹啮合、密封、锁扣、PE、针位防呆及安装空间必须有与本组合和工况一致的工程审核记录。
不能把另一个组合或工况的审核结果套用过来；资料修改会撤回工程审核。

实际目录运行结果：24V/3A/10 接点生成五类组件但待确认；17A 需求不符合样板额定参数；
两套压接方案需公、母普通端子各 20 个，PE 另核对。
不依据相同系列或相同尺寸编造配对关系，故实际数据仍未达到最终可确认状态。

选择模块的 15 项测试通过，包括仅存在于回滚测试 schema 的“全部已审核”正向用例。
该正向用例验证程序放行路径，不代表真实产品已获审核批准。
