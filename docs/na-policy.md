# NA数据规则

用户规定：不确定的数据统一标 **NA**，当前记录及新增数据不使用旧可用性状态。

- **known**：有明确数值或文字；审核状态单独保留。
- **NA（Not Available）**：暂无可确认数据。保留来源、原因和空数值，不填0、不借用相近型号。
- **not_applicable**：有依据确认不适用，与NA分开保存。

数值列保持数值类型，不能直接塞入文字NA；数据库用`value_state=NA`和空值保存，页面、CSV及`display_value`统一显示NA。原本尚未录入的字段同样展示NA，另以`availability_reason`区分未录入、未审核等情况，不伪造参数事实。

新比较接口使用`different_or_na`；导入计划使用`new_na`，添加统计使用`na_records`。可选线径、外径、温度接受NA输入；关键工况或组件参数为NA时仍保留待确认结果，不能当作校验通过。

002迁移在私有备份后，将实际20条记录转NA，每条保存迁移前后的审计；原数值、来源、审核决定及其他产品数据保留。已有001迁移及字段字典没有改写，迁移器按版本和校验和顺序执行。新数据库一次初始化即应用最新规则，旧库运行`python -m wain.migrations`升级。

当前实际参数为1129条known、20条NA，总计1149条；旧状态在当前参数表中为0条且禁止再次写入。历史审计保留原始前后事实，不追改历史事件。NA格式统一不等于产品或搭配已获工程批准。
