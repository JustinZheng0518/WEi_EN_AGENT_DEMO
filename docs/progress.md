## GitHub 与云环境中的内容

GitHub 保存源码、数据库定义、样板初始化逻辑、测试和说明。原始 PDF、实际数据库、OCR 原始结果、
CSV 导出及含原文页面的报告保留在云环境中，不随 Git 克隆下载。

因此，在其他机器克隆此仓库后，可以创建空数据库，但仍需提供原始 PDF 并执行导入，
或通过受控方式恢复现有备份。具体步骤见 [README](../README.md)。

## 当前功能边界

支持产品候选筛选、原文全文检索和页面追溯。全文 OCR 已完成，不等于全目录结构化建库已完成。
样板参数及搭配关系仍需审核，尚未实现完整方案求解、BOM 校验及大模型接入。
不能将当前查询结果描述为已验证合格的完整连接方案。
