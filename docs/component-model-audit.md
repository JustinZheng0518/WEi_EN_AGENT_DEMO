## 有实际意义的区别

- HA-003-M 与 HA-003-M-V2：已录导线截面上限分别为1.5和2.5 mm²。V2扭矩还带有变体确认条件，不能因为数值同为0.25 N·m而合并成无条件共有事实。
- HA-003-MS 与 HA-003-MQ：普通弹簧与Quick-in的最小线径分别为0.14和0.5 mm²；接触电阻上限分别为1和3 mΩ。普通弹簧未录入剥线值，不从Quick-in的10±0.5 mm继承。
- HA-010-M 与 HA-010-F：即使多数目录参数相同，性别、型号和订货号仍分别保留；数据库不会生成已批准配对。
- HA-010-MC 与 CESM-1.0：芯体与接触件是不同类别；芯体额定电压不会变成接触件的默认字段。接触件镀层也不传播成所有芯体的固定镀层。
